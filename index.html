Sobre mí

Me gusta construir sistemas que resuelvan problemas concretos. Para un cliente real desarrollé e instalé un sistema de ventas, stock, cuentas corrientes y facturación electrónica para un corralón y ferretería que antes trabajaba todo en papel.

En la carrera hice un sistema de stock y ventas para un local de bebidas y un sistema de gestión docente para un instituto. Por mi cuenta hice un sistema web de mantenimiento para una planta industrial y un CRM que ordena mi correo con inteligencia artificial.

Programo en Python, PHP, JavaScript y C, y trabajo con MySQL, SQLite y PostgreSQL (Supabase). Me interesan las herramientas internas: ordenar datos, automatizar tareas repetitivas y generar reportes que sirvan.

Proyectos

Cliente real, en uso

Sistema para corralón y ferretería

  • Python
  • Flet
  • SQLite

Sistema de escritorio a medida para un corralón y ferretería que trabajaba todo en papel. Lo desarrollé, lo instalé en el local y está en uso desde octubre de 2026, con versiones nuevas según lo que el cliente pide al usarlo.

  • Ventas y presupuestos en una sola pantalla, con buscador, lector de código de barras, atajos de teclado y recargos por tarjeta. Tickets en impresora térmica (ESC/POS).
  • Cuentas corrientes por semana, con pagos, actualización de deudas a precios de hoy y resumen en PDF para mandar por WhatsApp.
  • Productos por rubro y proveedor (pensado para 10.000), stock con historial, aumentos masivos con vista previa y deshacer, y pedidos a proveedores en PDF.
  • Facturación electrónica con ARCA: Factura C y nota de crédito con los web services oficiales, firma digital y código QR.
  • Caja, usuarios con permisos, copias de seguridad automáticas (también en Google Drive) e importación y exportación de Excel.
  • 584 pruebas automáticas, migraciones de la base de datos y una prueba de carga con 10.000 productos. Se instala como ejecutable para Windows.
El código es privado porque es de un cliente

Proyecto propio, en uso diario

Mail CRM: correo ordenado con IA

  • Python
  • FastAPI
  • JavaScript
  • Supabase
  • GitHub Actions

CRM personal que lee mi Gmail, ordena el correo con reglas e inteligencia artificial (Gemini) y me ayuda con la búsqueda laboral. La IA propone y yo decido: nada cambia en Gmail sin confirmación y todo se puede deshacer.

  • Clasifica cada mail con IA y aplica en Gmail papelera, archivo o estrella después de confirmar, con botón de deshacer.
  • Tablero de postulaciones: detecta mails de búsquedas laborales y avisa qué mails enviados quedaron sin respuesta.
  • Resumen diario escrito por la IA, avisos al celular (Web Push) y borradores de respuesta que nunca se envían solos.
  • App instalable (PWA) en Render con base de datos en Supabase y revisión automática cada 3 horas con GitHub Actions.
  • Auditoría de seguridad (CSP, sesiones revocables, Row Level Security) y 51 pruebas automáticas.

Proyecto propio

Mantenimiento de planta

  • React
  • Tailwind CSS
  • Supabase
  • PostgreSQL

Sistema web para el área de mantenimiento de una planta industrial: equipos, órdenes de trabajo y stock del pañol de repuestos.

  • Órdenes de trabajo preventivas y correctivas (pendiente, en curso y cerrada), con prioridad y técnico asignado.
  • Stock de repuestos con alerta de stock bajo; cada ingreso y retiro queda registrado con su orden de trabajo.
  • Reportes: órdenes por área, repuestos más usados y tiempo promedio de resolución, con exportación a CSV.
  • Roles de supervisor y técnico con Row Level Security, verificados con 29 pruebas automáticas.
  • Publicado en GitHub Pages con datos de prueba que se reinician todas las noches.

Proyecto de la carrera

Stock y ventas de bebidas

  • PHP
  • MySQL
  • HTML5
  • CSS3

Sistema web para que un local de bebidas controle su stock y sus ventas.

  • Catálogo con filtro por categoría (aguas, cervezas, gaseosas, isotónicas y jugos) y stock visible.
  • Carrito con cantidades editables, subtotales y total calculado automáticamente.
  • Cada pedido se confirma dentro de una transacción: se guarda completo o no se guarda, y descuenta el stock.
  • Panel de administración con resumen del día, alertas de stock bajo, productos y pedidos.
  • Contraseñas con hash, bloqueo tras intentos fallidos, protección CSRF y consultas preparadas.
