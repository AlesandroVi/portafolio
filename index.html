Hola, soy Alesandro

Estudio desarrollo de software y estoy cursando el tercer año de la carrera. Me gusta construir sistemas que resuelvan problemas concretos. Como proyectos de la carrera desarrollé un sistema de stock y ventas pensado para un local de bebidas y un sistema de gestión docente pensado para un instituto, que funciona como programa de escritorio para Windows. Por mi cuenta hice un sistema web de mantenimiento e inventario de repuestos pensado para una planta industrial.

Programo en Python, PHP, JavaScript y C, y trabajo con bases de datos MySQL, SQLite y PostgreSQL (Supabase). Me interesa construir herramientas internas que ordenen datos, automaticen tareas repetitivas y generen reportes útiles. Actualmente estoy aprendiendo a desarrollar aplicaciones web y móviles, con especial interés en las Progressive Web Apps (PWA).

Busco mi primera experiencia como desarrollador junior o trainee.

Proyectos

Sistema de Mantenimiento de Planta

Código Demo en línea

Sistema web, desarrollado como proyecto personal, para el área de mantenimiento de una planta industrial: equipos, órdenes de trabajo y stock del pañol de repuestos.

  • Órdenes de trabajo preventivas y correctivas con el ciclo pendiente, en curso y cerrada, prioridad y técnico asignado.
  • Stock de repuestos con alerta de stock bajo; cada ingreso y retiro queda registrado con su orden de trabajo.
  • Panel con reportes: órdenes por área, repuestos más usados y tiempo promedio de resolución, con exportación a CSV.
  • Roles de supervisor y técnico con permisos controlados en la base de datos con Row Level Security, verificados con 29 pruebas automáticas.
  • Publicado en GitHub Pages con datos de prueba que se reinician todas las noches.

Sistema de Gestión Docente

Código

Aplicación de escritorio, desarrollada como proyecto de la carrera, para la administración del personal docente de un instituto de nivel superior.

  • Alta, edición y búsqueda de docentes, con importación y exportación de planillas Excel.
  • Carreras, materias y designaciones, con control de licencias y suplencias.
  • Reportes de materias sin cubrir y de docentes ausentes sin suplente.
  • Constancias en PDF con los datos de la institución configurables.
  • Contraseña guardada como hash PBKDF2, copias de seguridad automáticas y pruebas unitarias de las validaciones.
  • Se distribuye como ejecutable para Windows.

Sistema de Stock y Ventas de Bebidas

Código

Sistema web en PHP y MySQL, desarrollado como proyecto de la carrera, pensado para que un local de bebidas controle su stock y sus ventas.

  • Catálogo con filtro por categoría (aguas, cervezas, gaseosas, isotónicas y jugos) y stock visible.
  • Carrito de pedidos con cantidades editables, subtotales y total calculado automáticamente.
  • Cada pedido se confirma dentro de una transacción: se guarda completo o no se guarda, y descuenta el stock.
  • Panel de administración con resumen del día, alertas de stock bajo, gestión de productos y listado de pedidos.
  • Contraseñas con hash, bloqueo tras intentos fallidos, protección CSRF y consultas preparadas.
